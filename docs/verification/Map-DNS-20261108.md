# Kiểm tra lại bản đồ sau sửa DNS — 08/11/2026

Nguyên nhân: DNS nhà mạng trả NXDOMAIN cho OpenStreetMap/Nominatim. Đổi IPv4 chưa đủ vì Wi-Fi còn DNS IPv6 nhà mạng. Sau khi Khang cập nhật cả IPv4 và IPv6 sang Cloudflare/Google:

- Resolver hệ thống phân giải được nominatim.openstreetmap.org và tile.openstreetmap.org.
- Ảnh nền OSM thực trả HTTP 200, image/png.
- Browser thật trên form Đăng địa điểm: chọn TP.HCM, nhập 25 Cô Giang, bấm Tìm vị trí → API nội bộ HTTP 200/success, Nominatim trả 3 gợi ý.
- Chọn một gợi ý điền được tọa độ, tạo ghim và tải được tile ở vị trí mới. Không gửi/lưu bài thử nghiệm.

Chỉ xác minh kết nối và luồng chọn tọa độ; không xác nhận gợi ý đầu tiên là đúng địa chỉ người dùng mong muốn. Địa chỉ có thể trùng tên, cần chọn và kiểm tra vị trí phù hợp. Không sửa code/routine hoặc database trong lần sửa DNS này.
